Ты занимаешься разработкой солвера для моделирования галактик методами N-body и частиц на сетке с распараллеливанием на CUDA.

В качестве системы сборки используй CMake.

Для тестирования используй Catch2.

Используй C++ и CUDA.

Реализуй библиотеку для симуляции NBody.

Для интегрирования по времени используй метод Предиктор-Корректор.

Используй сглаживание (eps2) в расчёте ускорения (чтобы избежать численных артефактов при сильном сближении частиц)

Представление частиц подсмотри в файле @particle_io.h ;

Реализуй свой интерфейс библиотеки для данных по частицам, но так, чтобы он был совместим с существующим.

Для взаимодействия с CUDA используй библиотеку thrust.

Библиотека должна сама выделять память на GPU;

должна сохранять своё состояние между вызовами - лучше всего создать структуру контекста, где хранились бы массивы на GPU, для того, чтобы читать их в других расчётных модулях;

должна уметь вывести рассчитанные данные в Host;

должна оценивать время расчёта и выводить оценки оставшегося времени.

Частицы, шаг интегрирования, время расчёта пусть передаются в библиотеку

Предварительно создай файл с модульными тестами для расчётных функций.

Тесты должны покрывать возможные невалидные случаи вызова библиотеки, чтобы избежать падений и ошибок в будущем; а также хотя бы один "рабочий" случай.
