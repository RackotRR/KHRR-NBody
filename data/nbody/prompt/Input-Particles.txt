Ты занимаешься разработкой солвера для моделирования галактик методами N-body и частиц на сетке.
Используй директорию khrr-lib.
Создай вложенную директорию particles для библиотеки чтения и сохранения частиц, ней - вложенные в неё директории src (для файлов .cpp) и include (для файлов .h).
В качестве системы сборки используй CMake.

Задача - создать методы чтения и записи данных по частицам.

Частицы могут быть сохранены в бинарном и текстовом виде.
Создай структуру для хранения векторных переменных (double3) для координат и скорости.

Бинарный вид записи:
Два файла для момента времени с названиями вида "S_%5d.bin" и "DM_%5d.bin", где число - номер шага по времени.
S-файлы содержат частицы соответствующие звёздам (stars, звёздная компонента);
DM-файлы содержат частицы, соответствующие тёмной материи (dark matter, компонента тёмной материи).
Вместо Си-форматирования строк используй библиотеку fmt.

В файлах сначала задано "Число частиц для компоненты (int)", затем "Момент времени (double)" (в бинарном виде).
Число частиц компоненты заранее известно, его нужно проверить, выдать предупреждение, если отличается, а прочитать минимальное количество - либо то, что передано, либо то, что заявлено в заголовке, либо сколько в целом удалось прочитать.
Далее идёт указанное количество частиц в виде X Y Z VX VY VZ (в бинарном виде, double), где X, Y, Z - координата, VX, VY, VZ - скорость.

Нужно прочитать файлы и создать два массива на выходе: массив координат и массив скоростей частиц; в массивах сначала должны идти все частицы звёзд, а затем частицы тёмной материи.
В результате чтения возвращай в том числе количество частиц каждой компоненты - это потребуется далее.

Добавь также возможность сохранения частиц в таком бинарном формате.

Текстовый вид записи:
Для этого формата требуется только чтение - это начальный момент для моделирования.
Особенностью является не только то, что данные записаны в виде текста, но и распределение по файлам.
Файлы имеют названия вида "start_S%d.txt" и "start_DM%d.txt", где число - номер галактики.
Соответственно, галактик может быть несколько, и пар файлов - тоже.
Каких-то файлов может не быть, если частиц какой-то компоненты нет.
Требуется прочесть сначала все файлы, соответствующие звёздной компоненте; а далее - все файлы тёмной материи.
Число частиц компоненты заранее известно, его нужно проверить, выдать предупреждение, если отличается, а прочитать минимальное количество - либо то, что передано, либо то, что заявлено в заголовке, либо сколько строк есть в файле.
Далее идёт указанное количество строк в формате csv, где разделителем является whitespace.
Для чтения лучше использовать специализированные библиотеки для работы с csv, либо форматированное чтение в стиле Си, чем стандартные потоки ввода - так значительно быстрее.
Формат строки для частицы следующий: "{X} {Y} {Z} {VX} {VY} {VZ}", где X, Y, Z - координата, VX, VY, VZ - скорость.
В результате чтения возвращай в том числе количество частиц каждой компоненты - это потребуется далее.
Для информации о галактиках используй структуру из файла khrr-lib\galaxy_params\include\galaxy_params.h

Тебе может потребоваться создать заголовочные файлы (оформляй в них документацию) и файлы реализации.


Создай файл с модульными тестами для проверки функционала. Используй библиотеку Catch2.
Тесты должны покрывать возможные невалидные случаи, чтобы избежать падений и ошибок в будущем.

namespace {

/// Быстрый парсер текстовых данных (аналог fscanf, но оптимизированный под пакеты)
static void read_text_component(const std::string& filepath, size_t max_count, size_t expected_count,
                                std::vector<double>& out_coords, std::vector<double>& out_vels, size_t& out_count) {
    FILE* f = std::fopen(filepath.c_str(), "r");
    if (!f) {
        out_count = 0;
        return;
    }

    int declared_n = 0;
    if (std::fscanf(f, "%d", &declared_n) != 1) {
        std::fclose(f);
        throw std::runtime_error(fmt::format("Failed to read particle count from {}", filepath));
    }
    size_t n_declared = (declared_n > 0) ? static_cast<size_t>(declared_n) : 0;

    if (n_declared != expected_count) {
        fmt::print(stderr, "Warning: Expected {} particles for {}, header declares {}\n", expected_count, filepath, n_declared);
    }

    size_t limit = std::min(max_count, n_declared);
    size_t read_n = 0;
    double x, y, z, vx, vy, vz;

    // Предвыделяем буфер под прочитанные данные
    size_t reserve_size = std::min(limit, (out_coords.size() + limit * 3)) * 3;
    out_coords.reserve(out_coords.size() + limit * 3);
    out_vels.reserve(out_vels.size() + limit * 3);

    while (read_n < limit && std::fscanf(f, "%lf %lf %lf %lf %lf %lf", &x, &y, &z, &vx, &vy, &vz) == 6) {
        out_coords.push_back(x);
        out_coords.push_back(y);
        out_coords.push_back(z);
        out_vels.push_back(vx);
        out_vels.push_back(vy);
        out_vels.push_back(vz);
        read_n++;
    }
    std::fclose(f);

    size_t available = std::fseek(f, 0, SEEK_END) == 0 ? 0 : read_n; // just logical
    (void)available;
    if (read_n != n_declared && read_n < limit) {
        fmt::print(stderr, "Warning: Read {} lines from {}, expected {}\n", read_n, filepath, n_declared);
    }
    out_count += read_n;
}

/// Чтение бинарной компоненты с пакетной оптимизацией
static void read_binary_component(const std::string& filepath, size_t max_count,
                                  std::vector<double>& out_coords, std::vector<double>& out_vels, size_t& out_count) {
    std::ifstream file(filepath, std::ios::binary);
    if (!file) {
        out_count = 0;
        return;
    }

    int declared_n = 0;
    double sim_time = 0.0;
    file.read(reinterpret_cast<char*>(&declared_n), sizeof(int));
    file.read(reinterpret_cast<char*>(&sim_time), sizeof(double));

    if (!file) throw std::runtime_error(fmt::format("Invalid header in {}", filepath));

    size_t n_declared = (declared_n > 0) ? static_cast<size_t>(declared_n) : 0;
    size_t available = 0;
    auto cur = file.tellg();
    file.seekg(0, std::ios::end);
    size_t file_bytes = static_cast<size_t>(file.tellg() - cur);
    file.seekg(cur);
    available = file_bytes / (6 * sizeof(double));

    if (n_declared != available) {
        fmt::print(stderr, "Warning: Declared count ({}) in {} differs from available data ({})\n", n_declared, filepath, available);
    }

    size_t n_read = std::min({max_count, n_declared, available});
    if (n_read == 0) return;

    std::vector<double> buffer(n_read * 6);
    file.read(reinterpret_cast<char*>(buffer.data()), n_read * 6 * sizeof(double));
    size_t actually_read = static_cast<size_t>(file.gcount()) / (6 * sizeof(double));
    n_read = actually_read;

    size_t prev_n = out coords.size() / 3;
    out_coords.insert(out_coords.end(), n_read * 3, 0.0);
    out_vels.insert(out_vels.end(), n_read * 3, 0.0);

    const double* src = buffer.data();
    double* c_dst = out_coords.data() + prev_n * 3;
    double* v_dst = out_vels.data() + prev_n * 3;

    for (size_t i = 0; i < n_read; ++i) {
        c_dst[0] = src[0]; c_dst[1] = src[1]; c_dst[2] = src[2];
        v_dst[0] = src[3]; v_dst[1] = src[4]; v_dst[2] = src[5];
        src += 6; c_dst += 3; v_dst += 3;
    }
    out_count += n_read;
}

} // namespace

ParticleData read_particles_binary(const std::string& base_path, int time_step, size_t max_stars, size_t max_dm) {
    ParticleData data;
    std::filesystem::path dir(base_path);
    read_binary_component((dir / fmt::format("S_{:05d}.bin", time_step)).string(), max_stars, data.coordinates, data.velocities, data.num_stars);
    read_binary_component((dir / fmt::format("DM_{:05d}.bin", time_step)).string(), max_dm, data.coordinates, data.velocities, data.num_dm);
    return data;
}

void write_particles_binary(const std::string& base_path, int time_step, double sim_time,
                            const std::vector<double>& coords, const std::vector<double>& vels,
                            size_t num_stars, size_t num_dm) {
    if (coords.size() != vels.size() || coords.size() % 3 != 0) {
        throw std::invalid_argument("Coordinate/Velocity array size mismatch or not divisible by 3");
    }
    size_t total = coords.size() / 3;
    if (num_stars + num_dm != total) {
        throw std::invalid_argument("Sum of component counts does not match total particles");
    }

    auto write_comp = [&](const std::string& fname, size_t n, size_t offset) {
        std::filesystem::path fp(std::filesystem::path(base_path) / fname);
        std::ofstream file(fp, std::ios::binary);
        if (!file) throw std::runtime_error(fmt::format("Cannot open {} for writing", fp));

        int n_int = static_cast<int>(n);
        file.write(reinterpret_cast<const char*>(&n_int), sizeof(int));
        file.write(reinterpret_cast<const char*>(&sim_time), sizeof(double));
        if (n == 0) return;

        const double* c = coords.data() + offset * 3;
        const double* v = vels.data() + offset * 3;
        std::vector<double> chunk(6);
        for (size_t i = 0; i < n; ++i) {
            chunk[0]=c[0]; chunk[1]=c[1]; chunk[2]=c[2];
            chunk[3]=v[0]; chunk[4]=v[1]; chunk[5]=v[2];
            file.write(reinterpret_cast<const char*>(chunk.data()), sizeof(double)*6);
            c+=3; v+=3;
        }
    };

    write_comp(fmt::format("S_{:05d}.bin", time_step), num_stars, 0);
    write_comp(fmt::format("DM_{:05d}.bin", time_step), num_dm, num_stars);
}

ParticleData read_particles_text(const std::string& base_path, const GalaxyParams& params) {
    ParticleData data;
    std::filesystem::path dir(base_path);

    // Предполагаем равномерное распределение лимита на галактики для контроля памяти
    size_t per_galaxy_s = params.expected_stars > 0 ? params.expected_stars / std::max(1, params.n_galaxies) : std::numeric_limits<size_t>::max();
    size_t per_galaxy_dm = params.expected_dm > 0 ? params.expected_dm / std::max(1, params.n_galaxies) : std::numeric_limits<size_t>::max();

    for (int i = 0; i < params.n_galaxies; ++i) {
        read_text_component((dir / fmt::format("start_S{}.txt", i)).string(), per_galaxy_s, data.coordinates, data.velocities, data.num_stars);
    }
    for (int i = 0; i < params.n_galaxies; ++i) {
        read_text_component((dir / fmt::format("start_DM{}.txt", i)).string(), per_galaxy_dm, data.coordinates, data.velocities, data.num_dm);
    }

    if (data.num_stars != params.expected_stars) {
        fmt::print(stderr, "Warning: Read {} star particles, expected {}\n", data.num_stars, params.expected_stars);
    }
    if (data.num_dm != params.expected_dm) {
        fmt::print(stderr, "Warning: Read {} DM particles, expected {}\n", data.num_dm, params.expected_dm);
    }

    return data;
}

static void remove_temp_dir(const fs::path& p) {
    if (fs::exists(p)) fs::remove_all(p);
}

TEST_CASE("Binary read/write roundtrip", "[binary]") {
    auto dir = create_temp_dir();
    int step = 12;
    double time = 1.5;

    std::vector<double> coords = {0,1,2, 10,11,12};
    std::vector<double> vels   = {0.1,0.2,0.3, 1.1,1.2,1.3};

    write_particles_binary(dir.string(), step, time, coords, vels, 1, 1);

    auto data = read_particles_binary(dir.string(), step, 10, 10);
    REQUIRE(data.num_stars == 1);
    REQUIRE(data.num_dm == 1);
    REQUIRE(data.coordinates.size() == 6);
    REQUIRE(data.velocities.size() == 6);

    REQUIRE(data.coordinates[0] == 0.0);
    REQUIRE(data.coordinates[3] == 10.0);
    REQUIRE(data.velocities[2] == 0.3);
    REQUIRE(data.velocities[5] == 1.3);

    remove_temp_dir(dir);
}

TEST_CASE("Binary read with mismatched header and available data", "[binary][edge]") {
    auto dir = create_temp_dir();
    int step = 5;

    // Файл заявляет 5 частиц, но содержит только 2
    std::ofstream f((dir / "S_00005.bin").string(), std::ios::binary);
    int n_declared = 5;
    double t = 0.0;
    f.write(reinterpret_cast<char*>(&n_declared), sizeof(int));
    f.write(reinterpret_cast<char*>(&t), sizeof(double));

    remove_temp_dir(dir);
}

### Краткие пояснения по реализации
1. **Производительность чтения**: В бинарном формате используется пакетное чтение в `std::vector`, а затем ручное распределение по массивам координат и скоростей без лишних реаллокаций. Для текста используется `std::fscanf`, что значительно быстрее `std::cin` или `std::istringstream` для простых числовых данных.
2. **Валидация**: При записи проверяется кратность размера массивов тройке и соответствие суммы компонент общему количеству. При чтении обрабатываются случаи несовпадения заголовка, физического объёма файла и переданного лимита.
3. **Путём к файлам**: `fmt::format("S_{:05d}.bin", step)` корректно заменяет `%5d` (с учётом того, что для файлов обычно подразумевается нулевое дополнение `%05d`). Если строго нужны пробелы в имени файла, замените `{:05d}` на `{:5d}`.
4. **Сборка**: `CMakeLists.txt` автоматически подтягивает `Catch2 v3` через `FetchContent`, поэтому тесты соберутся и запустятся командой `cmake -B build && cmake --build build && ctest --test-dir build`.
