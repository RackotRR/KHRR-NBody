Ты занимаешься разработкой солвера для моделирования галактик методами N-body и частиц на сетке с распараллеливанием на CUDA.
Используй директорию nbody-llm и вложенные в неё директории src (для файлов .cu) и include (для файлов .cuh).
В качестве системы сборки используй CMake.
Используй C++. Где можно - используй ленивые вычисления с библиотекой range-v3.

Текущая задача - создать методы чтения входных данных.

Начнём с чтения данных о параметрах галактик.

Они имеют следующий вид:
файл __start_galaxies.ini
1			---- количество галактик M_glx
0			---- номер галактики k_glx
262144,524288 		---- N_s[k_glx],N_dm[k_glx] (кол-во частиц каждой компоненты кратное 1024)
1.0,6.699356 		---- Mass_s[k_glx],Mass_dm[k_glx] (масса каждой компоненты)
0.004,0.004 		---- eps_s[k_glx],eps_dm[k_glx] (eps для каждой компоненты)
0.0			---- alpha_glx[k_glx] (угол наклона плоскости галактики в град.)
0.0,0.0,0.0		---- X_glx[k_glx],Y_glx[k_glx],Z_glx[k_glx] (положение центра масс галактики)
0.0,0.0,0.0		---- Vx_glx[k_glx],Vy_glx[k_glx],Vz_glx[k_glx] (скорость центра масс галактики)

Если галактик несколько (M_glx > 1), часть начиная с номера галактики повторяется.
Индекс _s означает звёздную компоненту, _dm означает компоненту тёмной материи.

Предварительно создай файл с модульными тестами для функций чтения параметров галактик.
Тесты должны покрывать возможные невалидные случаи, чтобы избежать падений и ошибок в будущем.
Напиши код для чтения такого файла: создай структуру данных и функции для чтения - тебе нужно будет создать заголовочный файл с подробной документацией и файл реализации.
